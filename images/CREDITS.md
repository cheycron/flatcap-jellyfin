# Screenshot artwork credits

The README screenshots show a throwaway Jellyfin 12.4.0 demo server. Its library is made only of the artwork below, with tiny generated placeholder clips (the video files are stills of the same images, never the films). Titles, years and one-sentence plots are written by the repository owner; no TMDB, IMDb, fanart or commercial poster is used, and the demo server has its internet metadata providers turned off.

Every image is taken from Wikimedia Commons, where the license is stated on the file page. Images were cropped and resized to fit posters (2:3), backdrops (16:9) and thumbnails; nothing else was changed. Attribution below is given as required by CC BY.

- **CC BY 2.5 / 3.0 / 4.0**: attribution to the credited author; link to the license; changes indicated (crop/resize).
- **Public domain**: as tagged on the Commons file page (the 1902-1927 works and their posters); no attribution is required, it is given for reference.
