# Inventory: what Jellyfin 12.4.0 paints

`src/jellyfin-inventory.json` is generated by `scripts/inventory.py` from the web client bundled with the server (`docker cp` of `/usr/share/jellyfin/web`) and from a running client (`qa/dump-vars.mjs`), because the `--jf-*` palette is declared by the MUI theme in JavaScript, not in a stylesheet.

How Jellyfin 12.4 themes the web client (verified in the bundle, not from memory):

- A MUI theme declares `--jf-*` custom properties (`--jf-palette-*`, `--jf-font-*`, `--jf-shadows-*`, …) on `[data-theme="dark"]` / `[data-theme="light"]`. The client sets `data-theme` on `<html>` from the user's *Theme* preference.
- Legacy theme CSS (`themes/<name>/theme.css`: dark, light, blueradiance, appletv, purplehaze, wmc) paints the old widgets, mostly through the same variables with literal fallbacks, plus some hard-coded colors (`#202020` card and dialog panels, scrollbars, guide categories).
- Application stylesheets hard-code the rest: the seek slider and volume slider (`#00a4dc`), switches, spinners, player popups, badges, progress bars.
- The font is `html{font-family:"Noto Sans",…}` plus the `--jf-font-*` shorthands.
- Branding Custom CSS is rendered by the client as an inline `<style>` element in the page layouts. It is **not** rendered in the admin Dashboard routes (checked, see the QA report).
